## How a missing row fails and how it recovers

A GAP stays until a later branch commits the receipt named above. Recovery is a new commit on that lane, then a recheck here: `git fetch` and `git show <branch>:<receipt path>`. This lane does not copy `eval/` onto `bot/mvp-docs-1031`. GAPs 7 and 8 are the rows that still fail that check.

`tests/test_mvp_1031_realfail_receipts.py` on realfail is the fail/recover pair for a bad committed receipt: the planted bad file is rejected, and a temp receipt that matches the report is accepted.
