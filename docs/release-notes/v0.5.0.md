# Deanery 0.5.0

First numbered product release of themark-net/pfy-deanery. There are no earlier
git tags; this note covers work that is already on `main`, taken from the git
log and from issue comments. It does not invent features.

The product version source of truth is `pyproject.toml` `[project] version`.
`pfy --version` and `pfylib.__version__` follow that field.

## Launcher

`pfy launch` is the operator entry for choosing a local harness and model
without writing harness config unless you run an explicit `pfy setup`.

- Claude Code, llama.cpp, Grok, and Cursor subscription paths have dry-run
  support, including `pfy launch --` passthrough and the TTY picker
  (`f69e1673`, `e7a7d460`, `2bc78b33`, `c832dde0`).
- Hermes and Gemini adapters include setup round-trips (`bb02c70b`).
- Cursor MCP and skills can be installed, checked with doctor, and uninstalled
  through `pfy setup` / doctor / uninstall (`84214968`).
- The Loop "Launch session" path writes the same apply ledger as the CLI
  apply path (`855d1ac5`).

## Updates and install

- `pfy --version` prints the product version. `pfy update --check` is
  read-only: it reports whether a newer ref is available and does not
  auto-update (`9c0a2f99`).
- `install.sh` defaults to the `main` branch. Optional `PFY_REF` pins a
  branch, tag, or SHA. A missing ref fails clearly and writes nothing
  (`51e7bef0`). Once the `v0.5.0` tag exists, pin this release with
  `PFY_REF=v0.5.0`. The default stays `main` until you set that.

## Catalog and runtime gates

- `pfy catalog validate` rejects secret-looking `args` and `env` values and
  does not print the secret in the failure text (`9b9748f5`).
- Ollama pulls over 25 GB are refused unless the operator opts in
  (`83a6e941`).
- The parked-lane cost gate skips unattended Grok calls unless a cost yes
  has been shown (`2ee92005`, `301fa433`).

## CORPUS and #305

- CORPUS / #309 follow-ups landed on main, including dropping the owner name
  from the public TODO row and keeping moved ops docs out of the sloptrim
  corpus (`3e180b12`, `6cf16e1e`, plus the related #309 test and build
  commits already on main).
- #305 non-nimo gaps closed: the Entry 148 real-HOME bind env hook was
  dropped, and tests cover the gate-hash / bwrap probes and the version-pin
  reason without a host bwrap (`5f583bb4`, `cd920dbf`, `3e7770e6`).

## Known limits

- `pfy launch` live exec is not in this release. The #53 live smoke on
  2026-11-17 at 6:02 PM PT ran
  `pfy launch claude-code --model ollama:qwen3.6:35b --yes` with a tiny
  prompt and exited 3 in 0.09s with "live exec is not in this Phase 3
  slice". The model was never loaded. Dry-run still works.
- Laguna (#25) and Colibri (#24 / T-0016) were not smoke-tested for this
  release: those weights were not already pulled on the smoke host, and
  the standing OK does not allow pulls.

Publishing (including a public MCP Registry / skills.sh listing), tags, and
GitHub releases stay gated. This document does not create the `v0.5.0` tag.
