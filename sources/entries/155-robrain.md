
### Entry 155: RoBrain: shared decision memory with structured vetoes and pre-task warnings

- **URL**: https://github.com/adelinamart/robrain (Apache-2.0, TypeScript monorepo, version 2.5.0). Checked at `HEAD` `ac53011016e5f7dd42bae9c00c1a9b7d207a68b8` (2026-10-29).

- **Source / Poster**: watch-list post by @DanKornas, https://x.com/DanKornas/status/2116682206122766587 (repo link in the reply thread)
- **Summary / Key Claims** (upstream README and docs; their claims except where marked verified): records what a team and its agents decide, and the alternatives they ruled out, as rows in Postgres with a structured `rejected[]` field (option and reason), captured passively from session turns (Claude Code plugin hooks, Codex hooks, an MCP server for Cursor, Copilot and Codex, and a Hermes memory-provider plugin under `integrations/hermes`). Decisions have a lifecycle (active, superseded, invalidated) and a graph; batch Synthesis flags contradictions, stance drift and recurring entities. Before a task, a two-tier veto check (`POST /veto-scan` exact match on `rejected[]`, then semantic recall) warns the agent before it re-proposes a rejected approach. Self-hosted stack is Postgres + pgvector (`pgvector/pgvector:pg16`) plus the Perception API in Docker; default providers are Anthropic (extraction) and OpenAI (embeddings), with a fully-local mode pointing the same `OPENAI_*` variables at Ollama, LM Studio or vLLM. `packages/vetobench` is an offline, deterministic retrieval bench (hash embedder, no API key) plus a `--live` behavioral layer with a deterministic, non-LLM judge. Headline behavioral claim "0 of 50 re-proposals with RoBrain vs 8-9 of 10 with no memory" (claude-haiku-4-5, five archived runs) is unverified here. Cloud mode (Rory Plans, roryplans.ai) is out of scope.
- **Why it matters here**: pfy-mentat's decision layer and handoff docs are full of "we tried X, it failed because Y" that later runs forget; a veto stored as data and surfaced before a task is exactly that missing piece. The Hermes provider matters because Mark chose Hermes as the bot interface (entry 134). It is a different axis from MemPalace (149, verbatim recall), cass-memory (108) and ai-memory (132): those answer "what did we say", RoBrain answers "what did we reject and why".
- **Fit on nimo**: Partly. The offline VetoBench needs only Node 20+ and a pnpm install inside DEVELOP (CPU only, no GPU or NVIDIA dependency). The real stack needs Docker (Postgres + pgvector + Perception) and either API keys or a local OpenAI-compatible endpoint on nimo (llama.cpp or vLLM would fit the Radeon 8060S, unverified with RoBrain). Docker availability on nimo not checked. Not staged on nimo; the smoke exits 2 there until it is.
- **Verified on the Grok Bot box** (clone under `/tmp`, Node 24.22.1, `pnpm install --frozen-lockfile --filter "@robrain/vetobench..."`, shared and vetobench builds): offline VetoBench PASS with veto recall@5 = 1.00 with files known and 0.70 without (10 scenarios, matching the README), the lifecycle suite 1.00 / 1.00 (4 scenarios), and the package's 22 node:test tests pass. - **Findings**:
  - `npx robrain up` pulls the Perception image from ghcr.io and writes credentials to `~/.robrain/stack/.env`; `robrain install` wires MCP into editor configs; `robrain init-project` writes `CLAUDE.md`, `AGENTS.md` and `.cursor/rules/robrain.mdc` into the project. Run none of these in Mark's checkout; a trial needs a scratch HOME and a scratch repo copy.
  - The Hermes provider ships turns to Perception, which runs extraction server-side, and fails open (recall degrades to nothing if Perception is down).
  - VetoBench has a documented third-party adapter interface (Mem0 is the reference adapter), so MemPalace or ai-memory could be scored on the same 10 trap scenarios. The behavioral layer and the Mem0 comparison need an LLM (`--live`); `LLM_PROVIDER` and `OPENAI_BASE_URL` are honored, so a local model on nimo is plausible (unverified).
  - The offline layer uses a bag-of-tokens hash embedder, so its 0.70 no-files number is a floor rather than what real embeddings would score.
